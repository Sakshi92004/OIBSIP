## Project Overview
This project applies RFM (Recency, Frequency and Monetary) analysis and K-Means clustering to segment customers based on their purchasing behaviour.

## Tools and Technologies
- Python
- Google Colab
- Pandas and NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Analysis Performed
1. Dataset inspection and cleaning
2. RFM feature calculation
3. Data transformation and standardisation
4. Elbow Method for selecting the number of clusters
5. K-Means clustering with four clusters
6. Customer segment profiling
7. Cluster visualisations and marketing recommendations

## Key Results
- Original dataset: 541,909 transactions
- Cleaned dataset: 392,692 transactions
- Unique customers: 4,338
- Total clusters: 4
- Highest-value segment: Cluster 0 (Champions)

## Project Files
- DataAnalytics_L1_Task2_Customer_Segmentation.ipynb – Complete analysis notebook
- Customer_Segmentation_Results.csv – Customer-level segmentation results
- Customer_Segment_Summary.csv – Cluster profile summary
- screenshots/ – Visualisation screenshots

## Conclusion
The project identifies four customer segments using RFM analysis and K-Means clustering. The results can help businesses improve customer retention, develop targeted marketing campaigns and increase customer value.
