## Project Overview

This project performs Exploratory Data Analysis (EDA) on a retail sales dataset using Python. The objective is to understand sales trends, customer demographics, product performance, and relationships between numerical variables.

## Tools and Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed

1. Dataset loading and inspection
2. Descriptive statistical analysis
3. Monthly and quarterly sales trends
4. Customer age-group and gender analysis
5. Product category and revenue analysis
6. Correlation heatmap
7. Additional visualization: Average sales by gender

## Key Findings

- Clothing recorded the highest quantity sold (894 units).
- Electronics generated the highest revenue (156,905).
- Female customers represented 51% of transactions and male customers 49%.
- Price per Unit and Total Amount showed a strong positive correlation (0.85).
- Average transaction amounts were nearly equal across genders.

## Conclusion

The analysis provides insights into retail sales patterns, customer demographics, and product performance. These findings can support inventory planning, pricing decisions, and targeted marketing strategies.
